## 2026-09-22 — HTML のメタデータ

**関連**: [phase0-learning-plan.md L1 / H1](../roadmap/phase0-learning-plan.md)

### `<title>` の役割

`<head>` に表示されるという理解は不十分。実際の役割は複数ある。

- 検索結果のリンクテキスト
- ブックマーク・閲覧履歴でのタイトル
- SNS 等での共有プレビューのタイトル（OGP の `og:title` が無い場合のフォールバックにもなる）
- スクリーンリーダーによる読み上げ（ページ遷移時に最初に読まれる）

ブラウザのタブに表示されるのは、上記の役割から見ると**副次的な効果**であって、
`title` タグの主目的ではない。

### メタデータの 5 分類

`<head>` 内のメタデータは役割で 5 つに分類できる。

1. **ブラウザに正しく解釈させるもの**
   - `<!DOCTYPE html>` — 互換モード（quirks mode / standards mode）に関わるらしい。詳細は要調査
   - `<html lang>` — 読み上げの発音言語、翻訳機能の判定に効く
   - `charset` — HTTP レスポンスヘッダの `Content-Type` より**優先される**文字コード指定
   - `viewport` — モバイルでの描画のされ方に関わる（詳細は要確認）
2. **文書のラベル付け**
   - `title`
   - `description` — 検索結果のスニペットなどに使われる
   - `canonical` — 別 URL で同一内容を返すページを「同じページ」として扱わせる指定
   - favicon
3. **共有時の見た目** — OGP (`og:*`) のデータ
4. **レンダリングのヒント** — 配色・テーマ (`theme-color` / `color-scheme` 等)
5. **クローラーへの指示** — `robots` 等

### 要調査（次回持ち越し）

- `<!DOCTYPE html>` と互換モードの関係
- `canonical` の具体的な使いどころ（重複 URL のパターン）
- 「レンダリングのヒント」に分類される項目の全体像
- 「クローラーへの指示」に分類される項目の全体像

## 2026-09-22 — skip link（スキップリンク）

**関連**: [phase0-learning-plan.md L2 / H2](../roadmap/phase0-learning-plan.md)

`nav` が大きい（項目数が多い・階層が深い）ページでは、スクリーンリーダー利用者が
ページを開くたびに `nav` の中身を全部読み上げられてから本文にたどり着くことになる。
**skip link** は、その `nav` を読み飛ばして本文 (`main`) へ直接ジャンプできるリンクのこと。

- 文書内の**先頭**（`body` の直後）に置く、本文へのアンカーリンク（例: `<a href="#main-content">本文へスキップ</a>`）
- 普段は視覚的に隠しておき、**キーボードフォーカスが当たったときだけ表示**するのが定番の実装
  （完全に非表示 `display: none` にすると、そもそもフォーカスが当たらず読み上げられない点に注意）
- マウス利用者には基本的に見えない・不要なもので、**キーボード / スクリーンリーダー利用者のための導線**という位置づけ

### 要調査（次回持ち越し）

- 「フォーカス時だけ表示」の具体的な CSS 実装パターン
- 飛び先 (`#main-content` 等) 側に必要な属性・マークアップ上の注意点
