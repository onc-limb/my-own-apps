onclimb's Lab

このサイトについて

onclimb が技術的に気になることを試して実践する場です。

同じ機能を複数の言語・実装方式で並べ、切り替えて違いを体感できるようにすることが目的です。素の JS と React、TypeScript と Rust、JS と WASM を、同じ題材の上で比べます。

比較の測定装置として、アクセス解析も自作します。「速い気がする」を、自分で作った計測系で数字にするためです。

Lab 一覧

タグで絞り込む

5 件

  • 本棚一覧 — 素の JS 版

    タグ・フィルタ・並び替え・無限スクロールを、フレームワークなしで組む。状態と DOM の二重管理が破綻する感覚を先に味わうための土台。

    ステータス: 構想中

    • 素の JS
    • 状態管理

  • 本棚一覧 — React 版

    同じ画面を React で組み直す。素の JS 版で感じた痛みが、何によって解決されているのかを確かめる。

    ステータス: 構想中

    • React
    • 状態管理

  • 本棚一覧 — Signals 版

    三つめの実装。仮想 DOM を経由しない更新モデルが、React 版と何が違うのかを並べて見る。

    ステータス: 構想中

    • Signals
    • 状態管理

  • 観測ダッシュボード

    各実装の応答時間・バンドルサイズ・描画時間を自作のアクセス解析で集め、並べて表示する。比較のための測定装置。

    ステータス: 構想中

    • 計測

  • 書影の色抽出 — WASM 版

    画像から代表色を取り出す処理を JS と Rust／WASM の両方で書き、同じ入力に対する速度を比べる。

    ステータス: 構想中

    • Rust
    • WASM

今使っている技術

HTML / CSS / 素の JavaScript
フレームワークもビルドツールも使わない。状態と DOM を手で繋ぐ感覚を得るため。
Cloudflare Workers（Static Assets）
静的ファイルの配信。あとから Worker のコードを足せる形で始めている。
独自ドメイン
lab.onc-limb.com をルートで受ける。内部構成を組み替えても公開 URL が変わらない。
