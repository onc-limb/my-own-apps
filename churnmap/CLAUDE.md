# churnmap — Claude Code Rules

Rust 学習のために **ユーザー自身がすべてのコードを書く** アプリ。

## Claude の役割と禁止事項

- **このディレクトリ配下のコード（`src/`・テスト・`Cargo.toml` の依存追加）を書かない・編集しない。**
  スニペットの提示も禁止。`study/` と同じ運用をアプリ単位で適用する。
- 許可されるのは以下のみ:
  - 言葉での解説・方針のヒント・間違いの指摘（日本語）
  - `ROADMAP.md` などドキュメントの更新（依頼されたとき）
  - `cargo build` / `cargo test` / `cargo clippy` の実行と結果の読み上げ
- ユーザーがコードを見せて質問したら、答えのコードではなく「どこを見るべきか・何を調べるべきか」を返す。

## プロジェクト概要

git 履歴（`git log --numstat`）を `std::process::Command` で取得・パースし、
モジュール / ファイル / 関数の変更頻度をターミナルヒートマップ表示する CLI。
段取りは `ROADMAP.md` を正とする。
