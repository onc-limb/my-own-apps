# debug-browser

ブラウザ上のエラーから、コンテキスト収集・修正パッチ生成・設計検証・HMR での再確認までを
1 つの流れで行うデバッグ特化のブラウザ。AI エージェント（TAKT など）が実装したコードの動作確認に使う。
