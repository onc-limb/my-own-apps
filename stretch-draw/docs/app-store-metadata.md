# Stretch Draw App Store Metadata

## 日本語

- 名前: Stretch Draw
- サブタイトル: 毎日ひとつ、迷わず伸ばす
- カテゴリ: ヘルスケア／フィットネス
- キーワード: ストレッチ,習慣,ガチャ,肩こり,柔軟,運動,リラックス
- プロモーション文: 選ぶ時間はゼロ。今日の1種を引いて、60秒だけ伸ばそう。

### 説明

Stretch Drawは、毎日ひとつだけストレッチを抽選します。

- 起動すると今日の1種が決まる
- 引き直しは1日1回だけ
- 朝・昼・夜で変わるストレッチ
- 継続すると新しい種目をアンロック
- ときどきSSR「今日は休んでいい券」
- 記録は「できた／まだ」だけ

秒数やメニューを入力する必要はありません。アカウント、広告、トラッキングもありません。

## App Review Notes

The app requires no account or network access. On launch it stores one local daily draw. A user may reroll once, start the fixed 60-second activity, and mark it complete. No health data is collected or transmitted.
