# Stretch Draw

毎日1種目だけ、ランダムなストレッチを提示するiPhoneアプリです。

起動するとその日の1種目を抽選し、固定60秒で実行して、「やった／やっていない」だけを記録します。
引き直しは1日1回までです。抽選結果と引き直し回数は端末内に保存されるため、再起動してもリセットされません。

## 開発環境

- Xcode 16以降
- iOS 17以降
- Swift 6 / SwiftUI / SwiftData
- XcodeGen

## 起動

```sh
xcodegen generate
open StretchDraw.xcodeproj
```

## v1.0の範囲

- 朝・昼・夜で変わる抽選テーブル
- Common / Rare / SSR（休息券）のレア度
- 連続達成日数による種目アンロック
- 1日1回だけの引き直し
- 60秒固定タイマー
- 完了／未完了だけの日次記録
- 将来有効化できるクライマー向け抽選テーブル

課金、アカウント、広告、解析、クラウド同期、姿勢推定は初回リリースに含めません。
