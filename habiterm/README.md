## 何だったか

習慣（毎日 / 週 N 回）とタイマーを組み合わせた iOS アプリ。2026-03 に開発が止まり、未リリース。

## なぜ終了したか

同じ課題意識で作った [`time-branch/`](../time-branch/)（階層プロジェクトの時間記録）と統合し、
**Week168**（週に配分できる時間の有限性を突きつける時間予算アプリ）として作り直すことにしたため。

- 習慣（回数ベースの達成記録）の概念は Week168 には引き継いでいない
- 論理日（一日の始まり）・バックヤード（アーカイブ）の考え方は引き継いでいる
