# TimeBranch プライバシーポリシー

最終更新日: 2026-08-06

TimeBranchは、プロジェクト、ページ、時間記録、表示言語を利用者の端末内に保存します。
これらのデータを開発者または第三者のサーバーへ送信しません。

TimeBranchは、アカウント、広告、アクセス解析、トラッキング、外部SDKを使用しません。
JSON書き出し機能で作成したファイルは、利用者が共有操作を行った場合に限り、利用者が選んだ共有先へ渡されます。

端末内のデータは、アプリ内の「すべてのデータを削除」またはアプリ自体の削除によって削除できます。
