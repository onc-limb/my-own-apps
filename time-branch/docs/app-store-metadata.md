# TimeBranch App Store Metadata

## 日本語

- 名前: TimeBranch
- サブタイトル: 階層でまとめる作業時間
- カテゴリ: 仕事効率化
- キーワード: 時間管理,工数,タイマー,プロジェクト,作業記録,集計
- プロモーション文: プロジェクトをタップするだけ。子プロジェクトの作業時間を親へ自動集計します。

### 説明

TimeBranchは、複数のプロジェクトを階層で整理して作業時間を記録するアプリです。

- プロジェクトをタップして計測を開始・停止
- 子プロジェクトの時間を親プロジェクトへ自動集計
- 日・週・月単位のレポート
- 時間記録の手動追加・編集
- 集計結果と記録のJSON書き出し

記録は端末内に保存されます。アカウント登録、広告、トラッキングはありません。

## English

- Name: TimeBranch
- Subtitle: Hierarchical Time Tracking
- Category: Productivity
- Keywords: time tracking,project,timer,hierarchy,work log,report
- Promotional text: Tap a project to track it. Time spent on child projects automatically rolls up to every parent.

### Description

TimeBranch tracks work time across projects organized in a hierarchy.

- Start or stop tracking with one tap
- Roll child-project time up to every parent
- Review daily, weekly, and monthly reports
- Add and edit entries manually
- Export reports and entries as JSON

All records stay on your device. No account, ads, or tracking.

## App Review Notes

TimeBranch requires no account or network access. Create a project from the Projects tab, then tap it from the Timer tab to start and stop tracking. JSON export opens the system share sheet only after a user action.
