# 2026-07-23 churnmap — git churn ヒートマップツールの企画・立ち上げ

## アイデア・背景

- git 履歴を調査して、どのモジュール / ファイル / 関数がよく変更されているかを
  ヒートマップで視覚的・数値的に表現する CLI ツールを作る。
- 動機は 2 つ: my-own-apps 自身の変更傾向の把握と、**AI コーディングに頼りすぎている反省から
  自分の手で Rust を書く** こと。学習が主目的。

## 決定事項

- 言語は Rust。アプリ名は `churnmap`（cargo プロジェクト作成済み）。
- git アクセスは `git2` クレートではなく `std::process::Command` で git CLI を叩く方式。
  理由: パースを自力で書くことが Rust の文字列処理の練習になり、移植も理解も楽。
- 段取りは `churnmap/ROADMAP.md` を正とする（Step 1〜5 で v0.1、関数レベルの Step 6 は別リリース）。
- **Claude は churnmap のコードを書かない**（スニペット提示も禁止）。`churnmap/CLAUDE.md` に明文化。
  Claude の関与は方向指示・間違いの指摘・ビルド/テスト実行までに限定する。
