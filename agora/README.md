# agora

ユーザーストーリーマッピングとイベントストーミングに特化したホワイトボードアプリ。

> ワークショップの成果物を、コードと同じように育てられるホワイトボード。

## 特徴（差別化の 3 本柱）

1. **手法特化** — USM / ES の構造をファーストクラスの概念として扱う
2. **音声 AI エージェント** — 付箋操作を音声で依頼し、議論に集中できる
3. **ファイルベース管理** — ボードはテキストファイル。git で履歴・差分・共有
