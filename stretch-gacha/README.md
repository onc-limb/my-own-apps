# ストレッチガチャ（StretchGacha）

ガチャを回すと「今やるストレッチ」が1本だけ出てくるiOSアプリです。
選ぶのが面倒でストレッチが続かない問題を、意思決定コストゼロ（回すだけ）と
レア度・図鑑コンプの収集欲で解決します。

- ガチャ: タップ1回で26種（ストレッチ24＋ご褒美カード2）からレア度重み付き抽選
- カード: 部位・レア度・手順・実施時間を1画面で表示
- タイマー: そのままカウントダウンで実施。完了はハプティクスで通知
- 記録: 実施履歴・連続日数（猶予1日方式）・図鑑登録
- 図鑑: 部位別グリッド。未入手はシルエット＋「???」
- 完全オフライン・ローカル完結（サーバー・アカウント・課金・広告なし）

## 開発環境

- Xcode 16以降
- iOS 17以降
- Swift 6 / SwiftUI / SwiftData
- XcodeGen
- 外部ライブラリ: なし（標準フレームワークのみ）

## 起動

```sh
xcodegen generate
open StretchGacha.xcodeproj
```

データ（実施記録・当日ドロー状態）は端末内のSwiftDataストアへ保存されます。
ネットワーク通信は一切行いません。

## 仕様ドキュメント

このアプリの仕様は veronica（iron-legion の上流工程パイプライン）の
L1（プロダクト定義）→ L2（機能仕様）→ L3（issue）で確定させたものです。
スナップショットを [`docs/upstream/`](docs/upstream/) に置いています
（正本は iron-legion 側の veronica-docs/stretch-gacha/）。

## 種目の追加

`StretchGacha/Resources/StretchCatalog.json` への追記だけで完結します
（コード変更不要）。記述規約は `CatalogValidator` とテストが機械的に検査します。
**一度実機に入れた種目の `id` はリネーム・削除しないこと**（実施記録の安定キーのため）。
